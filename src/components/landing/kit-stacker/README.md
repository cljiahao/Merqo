# src/components/landing/kit-stacker

Kit relationship visualization derived from KIT_NODES and KIT_EDGES. BlockTower renders selected kits with qkit at the base and uses brand-aware foreground tokens for live blocks; non-live blocks retain neutral surfaces. These previews describe configured relationships, not a guarantee that an integration is deployed.

BlockTower resolves selected slugs with the existing ecosystem nodeBySlug helper; it does not duplicate the relationship lookup.
